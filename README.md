# Higher Degree Glyph Designer v0.4.0

高阶贝塞尔单字形编辑器，原名 Quartic。双击 **`higher-degree-glyph-designer.html`** 即可离线使用，单文件包含所有脚本和样式，无需安装。也可打开 `index.html`（保留同目录 JS/CSS），或 `npm start` 后访问 `http://127.0.0.1:4173`。

版本变化持续维护于 [CHANGELOG.md](CHANGELOG.md)。历史标签保留，旧版生成文件可通过 Git 恢复；当前入口名称为 `higher-degree-glyph-designer.html`。

## v0.4.0：外观、度量与本地历史

- 深色 / 浅色 / 跟随系统；四套界面配色、高对比度、可配置 CSS 字体链和可改的工具快捷键。默认使用系统界面字体，不依赖任何额外安装的符号字体。
- 设置可选滚轮缩放或 Ctrl/Cmd+滚轮缩放，并可反转滚轮方向；滚轮缩放仍以光标所在位置为中心。
- 在画布拖动左右边距参考线，或拖动升部、大写高度、x 高和降部水平线。左边距移动字形轮廓并同步字宽，保持右边距；所有调整均可撤销。
- 单选控制点时按 `Shift+Delete` 将整段曲线拟合为低一阶 Bézier；`Delete` 继续执行直接删点。拟合最大误差会提示，操作可撤销。
- 节点模式多选节点后，单击其中一个已选节点即可切换缩放 / 旋转倾斜；轮廓模式保留双击切换。
- Unicode 栏支持输入带双引号的单个字符，例如 `"a"` 会转换为 `U+0061`；支持代理对之外的完整 Unicode 码位，包括补充平面字符。
- 可隐藏的时间线历史默认保留 100 步，设置范围 10–1000。IndexedDB 在本机保存各字形快照；可按字形或文件夹暂停/恢复，也可批量删除。关闭全局本地历史会警告并暂停后续写入，已有快照保留。
- 文件夹首屏字形会自动读取并绘制缩略图，不必先打开字形；页大小可选 30 / 60 / 100 / 200 或全部。文件夹超过 1000 个字形时选择单页模式会先警告。

历史数据留在当前浏览器的本地 IndexedDB，不会包含在项目文件、导出的字形 ZIP 或 GitHub 上传中。文件夹历史按文件夹名和相对路径关联；重新打开时请导入同一个文件夹。

## v0.3.1：布尔运算、交换格式与文件夹

### 多轮廓布尔运算

完整选择至少两个闭合轮廓 / 独立构件，在参数栏使用 **并集、交集、差集、异或**。差集基底可从下拉框选择，其余形状从该基底中减去。三个以上形状按列表顺序依次运算。

已组合的多个轮廓作为一个含字腔的形状，以偶奇填充参与运算。一个组合不是多个操作数，需要再选其他构件，或先取消组合。开放路径不能直接参与。高阶曲线先按 0.05 / 0.25 / 1 字体单位容差转换为三次，结果保留三次曲线和直线，未选中轮廓不变。运算结果可能为空；一次撤销恢复原始高阶数据。运算引擎为本地打包的 Paper.js。

### 单字形保存菜单

保存 `.glyph` 旁的 ▾ 菜单提供：

- **保存三次 Bézier .glyph**：本工具 JSON，仅含三次曲线和直线，使用与 SVG 完全相同的近似器、容差和六位小数输出。文件名默认 `名称.cubic.glyph`。这不是 Glyphs 软件的 OpenStep `.glyph`，不能仅凭扩展名认为能直接跨软件使用。
- **保存 UFO .glif**：标准 GLIF 2 单字形 XML，包含三次轮廓、字宽、Unicode，额外度量保存在命名空间 lib 中。导出时处理偶奇轮廓的字腔方向/交叠，适配字体常见的非零填充。开放路径保持开放。

导出仅转换副本，画布原始高阶曲线保持不变。`.glif` 是 UFO 的单字形文件；导入完整工程时需由目标软件登记字形，不是完整 `.ufo` 文件夹。

### 导入与文件夹识别

单文件导入和文件夹递归扫描支持相同的格式：

| 格式 | 支持内容 |
| --- | --- |
| .glyph | 本工具 Higher Degree v3 / 旧 Quartic v1、v2 JSON |
| .json | 仅识别同样的本工具字形 JSON，不把任意 JSON 当字形 |
| .glif | GLIF 1/2，直线、三次、二次隐含节点、开放路径、Unicode、零字宽 |
| .svg | path、矩形、圆/椭圆、线、多边形/折线、组变换和填充 |

SVG 自动单色化，按比例适配 700 单位高度及 50 单位左边距，保持长宽比；描边按开放中心线导入，**不扩展描边宽度**。文字、图片、`use` 引用、裁剪、蒙版、滤镜、外部资源和脚本不支持，会明确报错，需先在矢量软件中展开为普通路径。闭合填充形状会按其填充规则合并，保留字腔。不是完整 SVG 渲染器。

导入文件夹后，左栏列出全部候选文件，可收起、搜索、筛选修改项，首屏自动异步读取并显示实际轮廓缩略图。页大小可选 30 / 60 / 100 / 200 或全部；超过 1,000 个文件时选择全部会警告。每个字形保留独立修改、撤销/重做和画布视图；“返回独立字形”可回到打开文件夹前的工作。

UFO 文件夹里的 `.glif` 会被递归识别，读取同层 `contents.plist` 的名称映射和上级 `fontinfo.plist` 的度量。GLIF 引用构件需要同目录基字形，导入时按变换**展开为独立轮廓快照**，不保持动态引用；缺失/循环引用会报错。单独导入含引用构件的 GLIF 时，请改为导入完整文件夹。锚点、图片、辅助线和多个 Unicode 的额外映射不在本工具编辑范围，会提示。

### 文件夹保存

左栏“导出文件夹 ZIP”可导出全部可读取字形或仅修改项，格式可选原生高阶 `.glyph`、三次 `.glyph` 或 `.glif`。保留相对目录，格式转换产生重名时自动区分，ZIP 内附 `_higher-degree-export-report.json` 报告，明确列出跳过的坏文件。

**文件夹工作区保留在本次页面会话内，不会自动覆盖硬盘原文件。** 关闭前请保存单字形或导出 ZIP；当前字形的旧式自动草稿仍保留，但它不能替代整个文件夹备份。页面存在未导出的文件夹修改时会触发浏览器离开提醒。ZIP 是字形文件集合，不是完整 UFO 工程；不会伪造完整字体工程的其他文件。批量导出有约 150 MB 内存保护。

## 基本工具

| 工具 | 键 | 操作 |
| --- | --- | --- |
| 节点 | V | 拖点，左击曲线加平滑节点，右击加控制点，拖边缘改形 |
| 轮廓 / 构件 | A | 点击内部/边缘选全部点，Shift 多选，整体移动，空白框选 |
| 高阶钢笔 | P | 左键放节点，右键放控制点 |
| 直线 | L | 左键连续放节点 |
| 剪刀 | K | 点击剪开或拖线剪切全部交点 |
| 矩形 / 椭圆 | R / O | 拖动绘制，Shift 约束正方形/圆 |
| 平移 | H / 空格 | 拖动画布 |

点击首节点闭合，Enter 结束开放轮廓，Esc 取消未完成控制点；点击开放端点可续画。Del 真正移除控制点并降阶；删除轮廓节点后新邻接处用直线连接。降阶可能改形，可以撤销。

## 高阶曲线

**N 个内部控制点对应 N+1 次贝塞尔**，不是固定阶数 B 样条。0 个控制点是直线，1/2/3 个为二/三/四次，可继续增加。

“每段控制点上限”留空时不限制段内数量：右键始终保形加控制点，左键加平滑节点。设为非负整数后，达到上限时右键改为加节点。降低上限不会强制修改已有曲线。该设置对钢笔和节点编辑一致生效并保存本机。当前段的控制点数量也可直接输入，增加为保形升阶，减少会改形。

没有单段固定阶数限制，仍保留单文档 20,000 总点、导入 5 MB、坐标绝对值 1,000,000 的容量保护。控制点很多时会增加交互和导出耗时。

## 变换框和九宫格

完整轮廓或至少两个选中点显示变换框及参数栏“选择变换”：

- 拉伸/缩放：角手柄改变两个方向，边手柄改变一个方向；Shift 或“等比”保持宽高比。
- 轮廓模式双击选择切换旋转/倾斜，再双击切回；节点模式多选节点后，单击其中一个已选节点即可切换；角手柄旋转，边手柄作平行四边形剪切；Shift 旋转按 15° 对齐。
- 旋转中心十字可拖动，也可输入中心 X/Y；点击九宫格恢复预设。
- 九宫格以实际选中点的最小轴对齐包围矩形为准。中间是包围框中心，左下是最小 X/Y，其余类推；不采用点坐标平均值。
- X/Y 显示参考点位置，输入后整组平移；有自定义中心时显示该中心坐标。
- W/H 显示包围尺寸，按参考点拉伸。零宽/零高方向不能比例拉伸。
- 参数栏有轮廓方向反转按钮。九宫格同时作用于下方数值变换面板，也可显式选择字形原点。

**普通节点移动和组变换仅修改明确选中的点，未选中的关联控制柄固定。** 完整轮廓选择包含全部节点与控制点。每次拖动作为一条撤销记录，Esc 可取消。

## 拖点修饰键

| 按键 | 范围 | 行为 |
| --- | --- | --- |
| Alt | 平滑节点及其紧邻控制点 | 沿拖动开始时三点切线移动；其他未选中点固定；暂停普通吸附 |
| Ctrl（Mac 可用 Cmd） | 任意点/点组 | 相对拖动起点按水平、竖直或斜 45° 移动，不执行共轭约束 |
| Shift | **单独选中的一个平滑节点紧邻控制点** | 切线方向吸附至 0°/45°/90°；对侧柄共线且保持原长 |
| Ctrl+Alt | 同上，仅一个邻接控制点 | 与 Shift 共轭行为完全相同 |
| Ctrl+Alt+Shift | 同上 | 与上述共轭行为完全相同 |

Ctrl+Alt 在选择平滑节点本身或多个点时，**不联动未选中柄**，仅保留 Ctrl 方向约束。单柄共轭是“只动选中点”的明确例外。先单选控制柄，再按 Shift 拖动；其他情况下 Shift 仍用于多选和工具约束。

共轭以平滑节点为方向中心；Ctrl 单独使用以被拖动点的起始位置为方向中心。切换修饰键并继续移动时，从拖动起始状态重算；释放共轭后未选中柄恢复原位置。Esc 放弃整次拖动。

## 文件兼容与 SVG

`.glyph` 为单字形 JSON，新标识 `higher-degree-glyph`、`version: 3`。可导入旧 `quartic-glyph` v1/v2，保存统一输出 v3；旧编辑器不能读取 v3。

字体坐标 Y 向上，段 i 连接节点 i 与 i+1，闭合末段回首节点。0/1/2/3 个内部控制点沿用 `line/quadratic/cubic/quartic`，4 个及以上使用 `bezier`。节点可有 `smooth`；轮廓可有 `component` 和 `name`；内部 ID 不写入文件。完整示例见 `examples/a.glyph`。

新应用尝试迁移同源旧草稿/偏好；入口改名后的本地文件存储隔离依浏览器而异，升级前应从旧版下载 .glyph 再导入。自动草稿不是独立备份。

SVG 仍仅输出 `L` 和三次 `C`。低阶精确升阶；高阶采用端点/导数匹配的三次近似：

```
Q1 = P0 + n/3 * (P1-P0)
Q2 = Pn + n/3 * (Pn-1-Pn)
```

常用阶数将三次升至原阶，比较差值控制多边形以得到保守误差界，超限则 de Casteljau 二分；四次保留更紧的解析界。较高阶使用四阶导数控制多边形界给出 Hermite 余项 `M4*h^4/384`，避免大规模分割开销。求值采用稳定 Bernstein 权重，求根保持在 Bernstein 基底。

容差可选 0.05/0.25/1/2 字体单位，六位小数输出并预留舍入误差。复杂曲线超过细分保护时会明确报错。闭合路径偶奇填充，开放路径以 1 单位描边导出。SVG 是矢量图，不是字体文件。

不处理完整字体的字偶距、hinting 或可变字体；不导入 Glyphs OpenStep `.glyph/.glyphs`、FontForge SFD 或完整 OTF/TTF。UFO 支持范围是其 GLIF 及相关度量/引用信息，详见本页。

## 本地开发

Node.js 18+。固定版本 Paper.js 与 fflate 已本地打包，许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

界面中笔尖、剪刀、手形、网格等符号取自 Noto Sans Symbols 2 的字形轮廓，已按 Unicode 对应关系导出为 [SVG 精灵](assets/noto-symbols.svg)并内嵌到应用。发布物不包含原始 OTF 字体；衍生轮廓的 SIL OFL 1.1 许可证见 `assets/Noto-Sans-Symbols-OFL.txt`。

```sh
npm run build
npm start
```

当前公开镜像包含构建与运行文件；完整测试集保留在本地开发工作区。

- `geometry.js`：任意阶曲线、校验、SVG 近似。
- `operations.js`：升降阶、求交、剪刀、极值、吸附。
- `transform-box.js`：九宫格、仿射变换、修饰键几何约束。
- `glyph-io.js`：共享三次转换、原生三次文件和 GLIF 导出。
- `path-boolean.js`：闭合轮廓布尔运算、字腔方向处理；`vendor/`：固定第三方库及许可证。
- `file-import.js`：GLIF / SVG / 原生文件适配；`project-library.js`：文件夹状态、引用和批量导出。
- `app.js`：交互、历史、文件；`index.html/styles.css`：中文界面。
- `build.js`：生成单文件。
- `CHANGELOG.md`：持续维护发布记录；`REFERENCES.md`：参考说明。

高阶模型、编辑交互和文件夹管理为本项目实现；布尔/SVG 与 ZIP 功能使用上述 MIT 库。未打包其他字体编辑器的源代码。
