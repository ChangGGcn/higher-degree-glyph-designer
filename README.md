# Higher Degree Glyph Designer

**在浏览器中设计高阶 Bézier 字形。单文件、离线运行、支持三次曲线交换。**

An offline, browser-based glyph editor for arbitrary-degree Bézier curves, with cubic SVG / GLIF export.

[下载 v0.3.1](https://github.com/ChangGGcn/higher-degree-glyph-designer/releases/tag/v0.3.1) · [更新日志](CHANGELOG.md) · [MIT 许可证](LICENSE)

## 快速开始

1. 从 **Releases** 下载 `higher-degree-glyph-designer-v0.3.1.zip`。
2. 解压，用现代桌面浏览器打开 `higher-degree-glyph-designer.html`。
3. 编辑内置示例，或导入自己的字形。无需安装，无需连接服务器。

也可以下载本仓库后打开 `index.html`，保持旁边的脚本、样式和 `vendor/` 目录完整。推荐使用较新的 Chrome / Edge；移动端可查看和进行基本操作，精细编辑建议使用鼠标和键盘。

## 能做什么

- **高阶 Bézier**：两个端点之间允许任意数量的内部控制点；N 个控制点对应 N+1 次曲线，直线与不同阶数曲线可混用。
- **直接编辑**：拖节点、控制柄或曲线边缘；保形升阶和分割，真实删除控制点、降阶、取整和添加极值点。
- **选择与变换**：节点多选、轮廓/构件分组、画布缩放拉伸、旋转和倾斜；九宫格参考点、自定义旋转中心、精确坐标与尺寸。
- **布尔与剪切**：并集、交集、差集、异或；单点剪切、拖线剪切、端点连接、轮廓方向反转。
- **字体编辑辅助**：度量参考线、可调网格/节点/边缘吸附、固定实时预览、撤销/重做。
- **文件夹工作区**：递归浏览字形，搜索、分页、修改过滤；每个字形有独立编辑历史，可批量导出 ZIP。

运行时不向服务器上传字形，不加载 CDN 或在线字体。Paper.js 与 fflate 已随应用本地打包。

## 绘制与编辑

| 工具 | 快捷键 | 用法 |
| --- | --- | --- |
| 节点 | `V` | 拖点；左击曲线加平滑节点，右击加控制点，拖边缘改形 |
| 轮廓 / 构件 | `A` | 点击内部或边缘整体选择，Shift 多选，空白处框选 |
| 高阶钢笔 | `P` | **左键放节点，右键放控制点** |
| 直线 | `L` | 连续放置直线节点 |
| 剪刀 | `K` | 点击剪开，或拖一条线剪切所有交点 |
| 矩形 / 椭圆 | `R` / `O` | 拖动绘制，Shift 约束正方形或圆 |
| 平移 | `H` / 空格 | 拖动画布 |

钢笔点击首节点闭合；Enter 结束开放轮廓，Esc 取消未完成的控制点。右侧“每段控制点上限”留空表示不限；设定上限后，达到上限时右键改为添加节点。降低上限不会修改现有曲线。

普通点移动和组变换只影响**明确选中的点**，未选中的关联控制柄保持原位。完整轮廓选择则包括全部节点与控制点。

### 变换框与参考点

选择整个轮廓或至少两个点后，拖动角/边手柄进行缩放和拉伸。**双击选择**切换为旋转/倾斜模式：角手柄旋转，边手柄进行平行四边形剪切；再双击切回。Shift 约束等比缩放或 15° 旋转。

九宫格使用选中点的最小轴对齐包围矩形：中间为包围框中心，左下为最小 X/Y，其余类推。X/Y 修改参考点位置，W/H 调整整体尺寸。旋转中心可以拖动或输入坐标；零宽/零高方向不能比例拉伸。

### 拖点约束

| 按键 | 行为 |
| --- | --- |
| `Alt` | 平滑节点或其紧邻控制点沿原切线移动；暂停普通吸附 |
| `Ctrl` | 任意点相对拖动起点按水平、竖直、斜 45° 移动，不联动未选中柄 |
| `Shift` 或 `Ctrl+Alt` | **仅单选一个紧邻平滑节点的控制点时**：切线吸附到水平/竖直/45°，对侧柄共线且保长 |
| `Ctrl+Alt+Shift` | 与上述单柄共轭行为相同 |

先选中单个控制柄，再按 Shift 拖动；其他场景 Shift 保留多选和工具约束。选中节点本身或多个点时，Ctrl+Alt 不联动未选中柄。Mac 可用 Cmd 代替 Ctrl。

### 布尔运算

完整选择至少两个闭合轮廓或独立构件，在参数栏执行并集、交集、差集或异或。差集基底可选。分组轮廓作为一个包含字腔的操作数；一个组合内有多个轮廓时，仍需再选一个独立构件，或先解组。

高阶曲线先按容差转为三次再运算，结果为直线和三次曲线。未选中几何不变，空结果有效，一次撤销可恢复原始高阶数据。开放路径需先闭合。

## 文件格式

| 格式 | 导入 | 导出 | 说明 |
| --- | --- | --- | --- |
| `.glyph` | ✓ | ✓ | 本工具 JSON：原生高阶或三次曲线副本 |
| `.json` | ✓ | — | 仅接受本工具字形结构，不接受任意 JSON |
| `.glif` | ✓ | ✓ | GLIF 1/2 导入，标准 GLIF 2 三次字形导出 |
| `.svg` | ✓ | ✓ | 路径与基本形状导入，三次 SVG 导出 |

**本工具的 `.glyph` 不是 Glyphs 软件的 OpenStep `.glyph`。** 跨软件交换请选择 `.glif` 或 SVG。

保存按钮旁的 **▾** 可选择“保存三次 Bézier .glyph”或“保存 UFO .glif”。转换采用与 SVG 相同的算法，容差可选 0.05、0.25、1、2 字体单位；只转换下载副本，画布仍保留原始高阶数据。GLIF 导出处理字腔方向和交叠，以适配字体常见的非零填充规则。

### 导入范围

- **GLIF**：支持直线、三次、二次隐含节点、开放路径、Unicode、零字宽。UFO 文件夹可读取 `contents.plist` / `fontinfo.plist`，引用构件会按变换展开为独立轮廓快照；缺失或循环引用明确报错。
- **SVG**：支持路径、矩形、圆/椭圆、线、多边形/折线及组变换。单色化后按比例适配 700 单位高度和 50 单位左边距。描边仅导入中心线，不扩展宽度。文字、图片、外部引用、裁剪、蒙版和滤镜需先转换为普通路径。
- **原生文件**：保存使用 `higher-degree-glyph` v3，可读取旧 `quartic-glyph` v1/v2；旧编辑器不能读取 v3。示例见 [`examples/`](examples/)。

### 文件夹工作区

点击“导入文件夹”，左侧可收缩列表递归显示支持的文件；每页 60 项，按需解析，已打开字形显示轮廓缩略图。切换字形保留各自修改、撤销/重做和视图。

“导出文件夹 ZIP”可以只导出修改项，也可以导出全部可读取字形，选择原生 `.glyph`、三次 `.glyph` 或 `.glif`；保留相对目录并处理重名。坏文件会列入 `_higher-degree-export-report.json`。

**文件夹工作区只在当前会话中保留，不会自动覆盖磁盘文件。** 关闭前请下载单字形或批量 ZIP；当前字形的本地自动草稿不能替代整个文件夹备份。导出的 ZIP 是字形文件集合，不是完整 UFO 工程。

## 构建与源码

需要 Node.js 18+，**无需 `npm install`**：

```sh
npm run check
npm run build
npm start
```

本地服务仅监听 `127.0.0.1:4173`。构建会生成 `higher-degree-glyph-designer.html`，包括运行所需的脚本、样式及第三方许可证。

| 文件 | 用途 |
| --- | --- |
| `geometry.js` | 任意阶 Bézier、文件校验与三次近似 |
| `operations.js` / `transform-box.js` | 节点、剪切、吸附、仿射变换与修饰键 |
| `glyph-io.js` / `file-import.js` | 原生、GLIF、SVG 交换 |
| `path-boolean.js` | 三次轮廓布尔运算与字腔处理 |
| `project-library.js` | 文件夹状态与批量导出 |
| `app.js` / `index.html` / `styles.css` | 编辑器和界面 |
| `vendor/` | 固定版本的离线依赖及许可证 |

三次近似使用端点/导数匹配与误差上界驱动的自适应细分；常用阶数比较差值控制多边形，较高阶采用 Hermite 余项界。保形升阶和分割不强行取整，显式取整和降阶可能改变形状。

## 当前边界

- 单字形工具，不编辑完整字体的字偶距、hinting 或可变字体，不导入 OTF/TTF、SFD 或 Glyphs OpenStep 文件。
- 无单段固定阶数上限；仍有单文档 20,000 总点、单文件导入 5 MB、批量导出约 150 MB 的容量保护。较高阶数可能降低响应速度。
- GLIF 是单字形交换文件，加入目标 UFO 工程时需由目标软件登记；不是完整字体导出。
- 发布前已通过 56 项本地单元检查、三套浏览器回归，并用 fontTools 校验 GLIF 输出。开发测试及临时产物未随本次公开包上传。
